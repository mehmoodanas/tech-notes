# Python 3.15 is out: lazy imports, frozendict and a built-in sampling profiler

*13 October 2026*

Python 3.15.0 reached stable status on **9 October 2026**, according to python.org. It is a feature-heavy release, and several of the changes touch everyday code rather than just interpreter internals.

## What stands out

- **Lazy imports (PEP 810).** A new `lazy` soft keyword (`lazy import json`) defers loading a module until it is first used, which is aimed at cutting startup time for CLIs and large apps. It is only allowed at module scope; using it inside functions, classes or `try` blocks, or with star imports, is a `SyntaxError`.
- **`frozendict` (PEP 814).** A built-in immutable mapping. It is not a `dict` subclass, it is hashable when its keys and values are, and two instances with the same items compare equal regardless of insertion order.
- **`sentinel` (PEP 661).** A built-in way to create unique marker values with a clean repr, replacing the familiar `_MISSING = object()` pattern.
- **UTF-8 by default (PEP 686).** `open()` and friends no longer depend on the system locale when no `encoding` is given. This mostly helps Windows users, but the docs still recommend passing `encoding=` explicitly for portability, and you can opt out with `PYTHONUTF8=0`.
- **Tachyon sampling profiler (PEP 799).** A statistical profiler in `profiling.sampling` that can attach to a running process by PID and export pstats, flame graphs, Firefox Profiler or heatmap output.
- **Unpacking in comprehensions (PEP 798).** `[*L for L in lists]` flattens lists, and `{**d for d in dicts}` merges dicts.
- **Free-threaded stable ABI (PEP 803).** C extensions can target a stable ABI that works with free-threaded builds, which should make wheels for the no-GIL builds easier to ship.

## Why it matters

For data and backend work, the practical wins are likely lazy imports (faster tool startup), the UTF-8 default (fewer surprises when reading CSVs or logs on different machines) and an in-box profiler you can point at a live process. The stable ABI change is quieter but important for the scientific Python ecosystem's move towards free-threading.

## Before upgrading

The UTF-8 default can change behaviour for code that silently relied on a legacy locale encoding, so test file-handling paths. Third-party libraries also need time to publish 3.15 wheels; check your dependencies first. I did not benchmark any of these features myself, so I make no performance claims beyond what the docs state.
